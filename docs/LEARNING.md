가상환경 : 프로젝트마다 독립된 라이브러리 설치 공간을 만들어 주는 기능이다. 이를 쓰지 않으면 프로젝트마다 필요한 라이브러리 버전이 충돌하거나 컴퓨터 전역 Python 환경이 오염될 수 있다. 가상환경을 쓰면 프로젝트끼리, 그리고 컴퓨터 본체 환경과 서로 영향을 주지 않는다.

라우팅의 개념 : 요청이 들어온 주소와 방식(GET, POST 등)에 따라 어떤 함수가 처리할지 연결해 주는 것.
